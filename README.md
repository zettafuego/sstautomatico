# SST Automático

Genera un sistema de seguridad y salud en el trabajo de nivel 1 y lo deja listo para firmar.

## Abrir

- [GitHub Pages](https://zettafuego.github.io/sstautomatico/)
- En esta PC: abre `index.html`.

## Qué hay

- `templates.js` — el documento que se arma
- `app.js` — el llenado
- `scene3d.js` — la escena de presentación
- `iperc .xlsx` — la matriz IPERC de apoyo. El nombre del archivo lleva un espacio.

## Stack

HTML, CSS y JavaScript.
